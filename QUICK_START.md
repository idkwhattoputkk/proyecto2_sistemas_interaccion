# Quick Start Guide - Crystal Caverns

## 🚀 Get Playing in 3 Minutes

### 1. Install Dependencies
```bash
python install.py
```

### 2. Run the Game
```bash
python main.py
```

### 3. Play!
- Press **Enter** to advance through the story
- Experience **3D spatial audio** with each line
- Type **'quit'** to exit anytime

## 🎮 What You'll Experience

- **55+ Story Lines** with complete narrative arc
- **3D Audio Positioning**: Sounds from left, right, front, back
- **5+ Minutes** of immersive gameplay
- **Multiple Sound Types**: Footsteps, water, wind, doors, music

## 🔧 If Something Goes Wrong

### Audio Issues
```bash
# Try fallback audio
pip install pygame sounddevice
python main.py
```

### Python Issues
```bash
# Check Python version
python --version  # Should be 3.7+

# Install manually
pip install pyopenal numpy
```

### Test the Installation
```bash
python test_game.py
```

## 📁 Project Files

- `main.py` - The game itself
- `install.py` - Automatic setup
- `test_game.py` - Verify everything works
- `README.md` - Full documentation

## 🎧 Audio Setup Tips

- **Headphones recommended** for best 3D audio
- **Check system volume** before starting
- **Close other audio apps** for best performance

## ⚡ Quick Commands

```bash
# Full installation and test
python install.py && python test_game.py && python main.py

# Just run the game
python main.py

# Test only
python test_game.py
```
